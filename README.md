# ClickHouse

Система для загрузки данных с kafka в хранилище ClickHouse и выполнения запросов по данным.

## 🏗️ Архитектура

Компоненты системы:
1. **`interface`** (Streamlit UI):
   
   Представляет интерфейс (порт 8501)для симуляции потока данных в ML сервис и предоставляет возможность просмотра результатов скоринга.
    - Имитирует отправку транзакций в Kafka через CSV-файлы.
    - Загружает транзакции отдельными сообщениями формата JSON в топик kafka `transactions`.
    - Предоставляет информацию о транзакциях, сохраненных в БД
    

2. **`Kafka`**:
   - Zookeeper + Kafka брокер
   - kafka-setup: автоматически создает топик `transactions`
   - Kafka UI: веб-интерфейс для мониторинга сообщений (порт 8080)

3. **`clickhouse`**:
    - поднимается база данных ClickHouse для хранения данных по транзакциям
    - queries: sql запросы для инициализации базы данных и запрос, требуемый в задании
    - results: результирующая таблица запроса

## 🚀 Быстрый старт

### Требования
- Docker 28.2.2
- Docker Compose 2.36.2

### Запуск
```bash
git clone https://github.com/Timur-ingrzv/clickhouse-system.git
cd clickhouse-system

# Сборка и запуск всех сервисов
docker compose up -d --build
```
После запуска:
- **Streamlit UI**: http://localhost:8501
- **Kafka UI**: http://localhost:8080
- **Логи сервисов**: 
  ```bash
  docker-compose logs <service_name>  
  ```
## 🛠️ Использование

### 1. Загрузка данных:

 - Загрузите CSV через интерфейс Streamlit. 

### 2. Результаты:

 - Результаты выполненного запроса можно посмотреть через раздел **Show results** в Streamlit UI или в папке `clickhouse/results/`

## Оптимизация

Для ускорения выполнения запросов и оптимизации хранения данных были выполнены следующие действия:

1. ORDER BY по малокардинальным и часто используемых в запросах колонках (us_state, cat_id), что улучшает эффективность сжатия

2. Использование Low Cardinality для колонок (город, штат, категория), что уменьшает размер хранимых значений

3. Использование разных кодеков в зависимости от свойств колонки (double delta для даты, Gorilla для значений, варьирующихся в области среднего - координаты)
